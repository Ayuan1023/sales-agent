# 智能销售Agent全链路实战：从线索富集到CRM同步，8大模块自动化实现

> 传统SDR每天80%时间花在重复性工作上，真正用于高价值沟通的时间不足20%。本文实现一个全链路智能销售Agent，将8大环节全部自动化。

## 一、为什么需要智能销售Agent

我在和多家B2B公司交流时发现一个普遍痛点：销售团队花在找客户、写邮件、追跟进上的时间远超谈客户、签合同。一个SDR每天可能发50封邮件，但真正有质量的沟通不到5个。商业工具如HubSpot、Outreach虽然强大，但价格昂贵、个性化不足（大多是模板替换）、数据孤岛。

于是我决定自己做一个开源的智能销售Agent，用LLM实现真正的个性化。

## 二、系统架构

整体采用四层架构：展示层 -> API层(FastAPI) -> 业务层(8大Agent模块) -> 数据层(SQLite)。技术选型：FastAPI+Pydantic V2轻量高效；SQLite原生SQL避免ORM complexity；LLM复用项目统一封装；前端Bootstrap5+Axios单文件零构建。

## 三、核心模块实现

### 3.1 线索富集

输入公司名，返回完整公司画像。富集维度包括行业分类、员工规模、融资轮次、技术栈、关键决策人、购买信号。核心逻辑：先查公司基本信息，再关联联系人，最后检测购买信号（招聘动态/新闻等）。

### 3.2 智能评分

6维加权评分模型输出A/B/C三级。权重分配：公司规模25%、行业匹配20%、融资阶段15%、技术栈匹配15%、决策人可触达15%、信号强度10%。A级（>=80分）优先跟进，B级（60-79分）常规跟进，C级（<60分）低优先级。

### 3.3 个性化邮件生成

这是核心差异化模块。不是模板替换，而是基于客户具体情况用LLM生成。Prompt包含：客户公司名、联系人、行业、规模、技术栈、融资阶段、切入角度。要求：个性化开场（引用客户具体情况）、价值主张（针对客户痛点）、社会证明（相关案例）、明确CTA。字数150-200字，语气专业但不生硬。

### 3.4 跟进状态机

3-5封跟进邮件，第1/4/8/15天节奏。每封角度不同：第1封价值点切入，第4天案例分享，第8天紧迫感制造，第15天最后通知（breakup email）。状态机跟踪每封邮件的发送状态和回复情况，收到回复后自动停止后续跟进并触发回复处理。

### 3.5 回复自动分类

4类回复自动处理：感兴趣（自动提议会议时间，发送日历邀请）、拒绝（记录原因，停止跟进，加入抑制列表）、待定（设置3天后提醒，发送轻量跟进）、问问题（自动匹配FAQ回复，无法回答转人工）。

### 3.6 会议预约

推荐3个可选时间（基于工作日工作时段），生成日历邀请（.ics格式模拟），设置会前24小时提醒。

### 3.7 CRM同步

所有线索和沟通记录自动写入SQLite模拟CRM。每次操作记录同步日志（操作类型/时间/状态/详情）。支持线索状态流转：新线索->已触达->已回复->已预约->已转化。

### 3.8 ROI分析

实时统计：线索总数、已触达数、回复率、预约数、转化率、预计收入（转化数x客单价）、ROI倍数（预计收入/工具成本）。

## 七、跟进状态机设计

跟进状态机是保证不遗漏任何线索的核心。每个线索有以下状态：新线索、待发送第1封、已发送第1封、待发送第2封、已发送第2封、待发送第3封、已完成、已回复、已拒绝、已预约。状态流转由定时器和事件驱动：到达发送日期自动触发邮件发送；收到回复自动停止后续跟进并触发回复分类；回复为感兴趣自动转入会议预约流程。

## 八、回复分类的Prompt设计

回复分类是LLM应用的典型场景。Prompt设计要点：1）明确4个分类定义和边界；2）给出每个分类的示例；3）要求输出JSON格式便于解析；4）处理模糊回复（如我考虑一下归为待定）。经过调优，分类准确率可达90%以上。

## 九、ROI计算模型

ROI Dashboard的计算逻辑：预计收入 = 转化线索数 x 平均客单价；总成本 = 工具成本 + 人力成本（按处理时间折算）；ROI = (预计收入 - 总成本) / 总成本 x 100%。以10人销售团队为例，工具成本为0（开源），人力成本从每人每天4小时降至1小时，年节省人力成本约60万，转化提升带来的收入增加约50万，综合年收益110万。

## 十一、实战经验总结

在开发过程中有几个关键经验：1）Prompt工程比模型选择更重要，好的Prompt能让7B模型达到70B模型的效果；2）状态机比自由流程更可靠，销售跟进必须有明确的状态流转和超时处理；3）模拟数据要足够真实，字段设计要考虑生产环境的实际情况；4）评测要覆盖边界条件，空输入、超长输入、特殊字符都要测试。

## 十二、与商业工具的成本对比

以10人销售团队为例：HubSpot Sales Hub专业版约$500/月（约3600元），年成本4.3万；Outreach约$100/用户/月，年成本8.6万；Apollo约$50/用户/月，年成本4.3万。本Agent开源免费，仅需服务器成本（约100元/月），年成本1200元。三年累计节省20-25万。更重要的是，本Agent可深度定制，完全匹配业务流程，而商业工具只能适配其标准流程。
