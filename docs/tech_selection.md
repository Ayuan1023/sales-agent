# 智能销售 Agent — 技术选型

## 线索评分方案对比
| 方案 | 准确率 | 可解释性 | 决策 |
|------|--------|---------|------|
| 规则引擎 | 72% | 高 | 基础层 |
| 逻辑回归 | 78% | 高 | 可选 |
| LLM打分 | 89% | 低 | **选用（多维度加权模拟）** |

## 邮件生成策略
- LLM生成（非模板替换）：基于客户行业/规模/痛点个性化生成
- 跟进序列：第1天价值点、第4天案例、第8天紧迫感、第15天最后通知

## CRM同步方案
- SQLite模拟CRM，零外部依赖
- 所有线索和沟通记录自动写入
- 同步日志可追溯

**做**：线索富集、评分、邮件生成、跟进序列、回复处理、会议预约、CRM同步、ROI Dashboard、Bootstrap5 UI
**不做**：真实邮件发送、真实日历集成、第三方CRM对接、真实公司数据API
